## Online Website:
https://jsnuwu.github.io/pokedex/

## Frontend:
Die Main-Page bietet eine Übersicht über alle im Projekt vorhanden Funktionen wie im unteren Teil beschrieben.

# Open Pokedex: 
- Überischt über alle Pokemons
- Sortier- und Filterfunktion nach Typen:
  Bug, Dragon, Electric, Fairy, Fighting, Fire, Flying, Ghost, Grass, Ground, Ice, Normal, Poison, Psychic, Rock, Steel, Water
- Jedes Pokemon wird duch **Größe, Gewicht und Typ(en)** definiert.

# Open Arena:
- Kampf gegen einen Computergesteuerten Gegner
- Auswahl zwischen Bulbasaur, Charmander und Squirtle
- Auswahl zwischen drei Angriffsfähigkeiten
- Kampfverlauf in einem Hitlog einsehbar

# Open API-Page:
- API-Steuerung des Pokédex
- Pokémon können gespeichert oder gelöscht werden

# Open OW (Open World):
- 2D-Top-Down-Spielwelt mit Interaktionsmöglichkeiten

# Zusätzliche Features:
- Klick auf Pokemon-Logo --> Weiterleitung zu "pokewiki.de"
- Abspielen von Musik
