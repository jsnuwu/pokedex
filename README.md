# Pokédex Projekt
**Live-Demo:** [jsnuwu.github.io/pokedex](https://jsnuwu.github.io/pokedex/)

## Übersicht
Das Projekt ist eine interaktive Web-Anwendung rund um Pokémon (Gen 1) mit mehreren Modulen:
- **Open Pokedex** – klassischer Pokédex mit Filterfunktionen  
- **Open Arena** – Kampfmodus gegen KI-Gegner  
- **Open API-Page** – Schnittstelle zum Verwalten der Pokémon  
- **Open OW (Open World)** – kleine 2D-Spielwelt mit Minigames  
- **Zusatzfeatures** – Musikplayer, Easter Eggs und externe Links 

# Open Pokedex: 
- Übersicht über **alle Pokémon der 1. Generation**
- Filter- und Sortierfunktionen nach Typen:
  `Bug, Dragon, Electric, Fairy, Fighting, Fire, Flying, Ghost, Grass, Ground, Ice, Normal, Poison, Psychic, Rock, Steel, Water`
- Anzeige von **Größe, Gewicht und Typ(en)**

# Open Arena:
- Kampf gegen einen **computergesteuerten Gegner**
- Auswahl zwischen **Bulbasaur, Charmander oder Squirtle**
- 3–4 unterschiedliche Angriffsfähigkeiten
- **Hit-Log** für den Kampfverlauf
- Zufällige Gegnerauswahl (von drei möglichen Pokémon)

# Open API-Page:
- API zur **Steuerung des Pokédex**
- Pokémon können **gespeichert oder gelöscht** werden

# Open OW (Open World):
- 2D-Top-Down-Spielwelt mit Interaktionsmöglichkeiten
- Verlinkungen auf die Anderenseiten eingebaut
- Kleine Minigames als Extra

# Zusätzliche Features:
- Klick auf das **Pokémon-Logo** → Weiterleitung zu [pokewiki.de](https://www.pokewiki.de/)  
- Klick auf den **Pokémon-Title** → Weiterleitung zu [pokemon.com](https://www.pokemon.com/)  
- Abspielen von Musik über den Radio Player
- Versteckte Eastereggs des Teams
